The CKomposable engine entry point: CKEngine.RunAsync runs an EngineConfiguration and returns an EngineResult (its RunStatus and the result of each BinPath). The generated map of each App is an ICKomposableMap: its CompiledConfiguration holds the values burnt by the build. The engine owns the run: it calls the phases of the StObj engine and, for each App, completes its source code (AppGenContext), signs it, saves it (G0.cs) and compiles it.
