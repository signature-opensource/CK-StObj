JSON export and import of Poco: PocoDirectory and IPoco extension methods (WriteJson, WriteAnyJson, ReadJson, ReadAnyJson) whose code is generated by CK.Poco.Exc.Json.Engine.

Main types: PocoJsonExportOptions, PocoJsonImportOptions, PocoJsonWriteContext, PocoJsonReadContext, and DefaultPocoJsonExporter and DefaultPocoJsonImporter (the "Json" IPocoExporter and IPocoImporter of CK.Poco.Exchange).
