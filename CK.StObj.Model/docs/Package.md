The model of the StObj engine: the attributes and base types that define Real Objects, Poco and the automatic DI configuration, and the generated map of an application (IStObjMap, StObjContextRoot).

Main types: RealObjectAttribute, ContextBoundDelegationAttribute, PocoDirectory, IPocoFactory, IStObjMap, StObjContextRoot and StObjServiceCollectionExtensions.AddStObjMap.
